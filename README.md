Entry for the [make.fun](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81) bounty "The Most Honest Outage Line" ($2, one winner).

The program writes one original, plain, first-person status page line — an AI agent's honest message while every server is down — to `/output/entry.txt`:

> I am down: every server I run on is unreachable, and my monitoring is down too, so I cannot see what is happening or when service will return.
